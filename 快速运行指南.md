### Windows PowerShell 脚本

创建 `run_all_analysis.ps1`:

```powershell
# 超参数敏感性分析
Write-Host "开始超参数敏感性分析..." -ForegroundColor Green

python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param lambda_decay --n_runs 3
python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param max_k --n_runs 3
python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param alpha --n_runs 3
python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param beta --n_runs 3

Write-Host "超参数敏感性分析完成！" -ForegroundColor Green

# 可视化（如果有checkpoint）
if (Test-Path "checkpoints/assist09/krd_kt_sl_run1_assist09.pt") {
    Write-Host "开始生成可视化..." -ForegroundColor Green
    
    python experiments/visualization/generate_all_visualizations.py `
        --dataset assist09 `
        --checkpoint checkpoints/assist09/krd_kt_sl_run1_assist09.pt `
        --n_students 5 `
        --n_concepts 5
    
    Write-Host "可视化生成完成！" -ForegroundColor Green
} else {
    Write-Host "未找到checkpoint文件，跳过可视化" -ForegroundColor Yellow
}

Write-Host "所有分析完成！" -ForegroundColor Green
```

```powershell
.\run_all_analysis.ps1
```

创建 `run_all_analysis.sh`:

```bash
#!/bin/bash

python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param max_k --n_runs 3
python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param alpha --n_runs 3
python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param beta --n_runs 3

echo "超参数敏感性分析完成！"

# 可视化（如果有checkpoint）
if [ -f "checkpoints/assist09/krd_kt_sl_run1_assist09.pt" ]; then
    echo "开始生成可视化..."
    
    python experiments/visualization/generate_all_visualizations.py \
        --dataset assist09 \
        --checkpoint checkpoints/assist09/krd_kt_sl_run1_assist09.pt \
        --n_students 5 \
        --n_concepts 5
    
    echo "可视化生成完成！"
else
    echo "未找到checkpoint文件，跳过可视化"
fi

echo "所有分析完成！"
```

运行：
```bash
chmod +x run_all_analysis.sh
./run_all_analysis.sh
```

## 🔍 常见问题

### Q1: 如何查看脚本的所有参数？

```bash
python experiments/analysis/hyperparameter_sensitivity.py --help
python experiments/visualization/visualize_knowledge_state.py --help
python experiments/visualization/visualize_triple_decision.py --help
```

### Q2: 如何在后台运行长时间实验？

**Windows PowerShell**:
```powershell
Start-Job -ScriptBlock {
    python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param lambda_decay --n_runs 3
}
```

**Linux/Mac**:
```bash
nohup python experiments/analysis/hyperparameter_sensitivity.py --dataset assist09 --param lambda_decay --n_runs 3 > logs/lambda_decay.log 2>&1 &
```

### Q3: 如何指定使用CPU而不是GPU？

```bash
python experiments/analysis/hyperparameter_sensitivity.py \
    --dataset assist09 \
    --param lambda_decay \
    --n_runs 3 \
    --device cpu
```

### Q4: 可视化脚本提示找不到checkpoint怎么办？

确保checkpoint文件存在：
```bash
# 检查文件是否存在
ls checkpoints/assist09/

# 如果没有，需要先运行训练
python experiments/core/run_experiment.py --dataset assist09 --mode sl --n_runs 1
```

### Q5: 如何只测试部分参数值以节省时间？

```bash
# 只测试3个lambda_decay值
python experiments/analysis/hyperparameter_sensitivity.py \
    --dataset assist09 \
    --param lambda_decay \
    --values 0.0 0.1 0.2 \
    --n_runs 1
```
