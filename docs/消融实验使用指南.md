# 消融实验框架使用指南

> **创建时间**: 2026-02-13  
> **版本**: v1.0

---

## 📋 概述

消融实验框架已集成到 `experiments/run_experiment.py` 中，通过 `--mode` 参数控制不同的模型变体。

---

## 🎯 支持的消融模式

| Mode | 说明 | 关键修改 |
|------|------|----------|
| `full` / `default` | KRD-KT 完整版 | Phase 1 + Phase 2 RL, n_epochs=100 |
| `sl` | KRD-KT-SL | 仅Phase 1, n_epochs=50 |
| `wo_3wd` | w/o Three-way Decision | use_triple_decision=False (标准GNN) |
| `wo_multi` | w/o Multi-order | max_k=1 (仅一阶邻居) |
| `wo_diff` | w/o Diff-Msg | use_diff_msg=False (统一消息传递) |
| `wo_decay` | w/o Decay | lambda_decay=0.0 (无距离衰减) |
| `wo_neg` | w/o Neg-Suppress | use_neg_suppress=False (无负域抑制) |

---

## 🚀 使用方法

### 基本命令
```bash
python experiments/run_experiment.py --dataset <DATASET> --mode <MODE> --n_runs 5
```

### 参数说明
- `--dataset`: 数据集名称 (`assist09`, `junyi`, `ednet`, `all`)
- `--mode`: 消融实验模式 (见上表)
- `--n_runs`: 运行次数 (默认5次)

---

## 📝 使用示例

### 1. 运行完整模型 (KRD-KT)
```bash
python experiments/run_experiment.py --dataset assist09 --mode full --n_runs 5
```

**输出文件**:
```
checkpoints/assist09/krd_kt_run{1-5}_assist09.pt
results/krd_kt_run{1-5}_assist09.json
results/krd_kt_assist09.json
```

### 2. 运行KRD-KT-SL (仅Phase 1)
```bash
python experiments/run_experiment.py --dataset assist09 --mode sl --n_runs 5
```

**输出文件**:
```
checkpoints/assist09/krd_kt_sl_run{1-5}_assist09.pt
results/krd_kt_sl_run{1-5}_assist09.json
results/krd_kt_sl_assist09.json
```

### 3. 运行 w/o Three-way Decision
```bash
python experiments/run_experiment.py --dataset assist09 --mode wo_3wd --n_runs 5
```

**输出文件**:
```
checkpoints/assist09/krd_kt_wo_3wd_run{1-5}_assist09.pt
results/krd_kt_wo_3wd_run{1-5}_assist09.json
results/krd_kt_wo_3wd_assist09.json
```

### 4. 批量运行所有消融变体
```bash
#!/bin/bash
# run_all_ablations.sh

DATASET="assist09"
MODES=("full" "sl" "wo_3wd" "wo_multi" "wo_diff" "wo_decay" "wo_neg")

for MODE in "${MODES[@]}"; do
    echo "Running mode: $MODE"
    python experiments/run_experiment.py --dataset $DATASET --mode $MODE --n_runs 5
done
```

## ⚙️ 技术实现细节

### 配置覆盖机制
1. 加载数据集基础配置 (`get_dataset_config`)
2. 获取消融模式配置覆盖 (`get_ablation_mode_config`)
3. 合并配置 (`config.update(ablation_config)`)
4. 传递给模型初始化

### 模型架构适配
- `KRDKT.__init__`: 接收消融参数并传递给子模块
- `TripleDecisionGraph.__init__`: 存储消融配置
- `TripleDecisionGraph._aggregate_one_node`: 根据配置切换聚合逻辑
- `TripleDecisionGraph._message_passing_region`: 根据配置切换消息传递

### 关键判断逻辑
```python
# w/o Three-way Decision
if not self.use_triple_decision:
    # 所有邻居统一处理
    m_k = self._message_passing_region(..., region_type='unified')

# w/o Diff-Msg
if not self.use_diff_msg:
    # 所有区域使用相同MLP
    mlp = self.mlp_pos[str(k)]

# w/o Neg-Suppress
if region_type == 'neg' and self.use_neg_suppress:
    message = -gamma * message  # 仅在启用时抑制
```

## 📈 预期实验结果

根据消融实验理论，预期性能排序（AUC从高到低）：

## 🐛 故障排查

### 问题1: 配置参数未生效
**现象**: 训练日志显示的配置与预期不符

**解决**: 检查 `get_ablation_mode_config` 返回的字典，确认参数名正确

### 问题2: 模型行为异常
**现象**: w/o三支决策但仍然划分区域

**解决**: 检查 `TripleDecisionGraph._aggregate_one_node` 中的判断逻辑

### 问题3: 文件命名错误
**现象**: checkpoint文件名与预期不符

**解决**: 检查 `get_mode_variant_name` 返回值是否正确
