## 💡 关键经验速查

### 图构建

```
✅ 混合方法 = 领域知识（质量）+ 数据驱动（覆盖）
✅ top_k 不是越大越好，需要平衡
✅ 图密度建议: 5-15%
✅ 平均邻居数建议: 5-15
```

### 训练稳定性

```
✅ 梯度裁剪是必须的（grad_clip=1.0）
✅ 模型规模要与数据匹配
✅ 大数据集用小学习率
✅ 大batch提高稳定性
```

### 训练速度

```
✅ 序列长度基于数据分布选择（75分位数）
✅ patience不要过大（5-8即可）
✅ warmup_steps不要过多（1000-2000）
✅ batch_size尽量大（GPU允许）
```
