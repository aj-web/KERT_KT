## 🎯 训练策略（论文3.6.2节）

### 两阶段训练
1. **Phase 1**: KT预训练（前50 epochs）
   - 纯监督学习
   - 学习率: 0.001
   - 训练KT预测器和图模块

2. **Phase 2**: RL微调（后50 epochs）
   - 联合训练：KT loss + RL loss
   - 学习率降低: 0.0005
   - 优化三支决策阈值

### 优化策略
- **Warmup**: 前1800步学习率预热
- **LR Decay**: ReduceLROnPlateau (patience=5, factor=0.5)
- **Early Stopping**: patience=5（ASSIST09）
- **L2正则化**: λ=1e-5

## 🔧 关键参数说明

### 模型结构
- `embed_dim`: 概念和题目嵌入维度
- `hidden_dim`: LSTM隐藏层维度
- `n_layers`: 图传播层数L（默认2）

### 三支决策
- `alpha`: 正域阈值（论文：0.7）
  - s_ij ≥ α → 强相关邻居
- `beta`: 负域阈值（论文：0.3）
  - s_ij ≤ β → 弱相关/负相关
- `lambda_decay`: 距离衰减系数λ
  - ω(k) = λ^(k-1)

### 强化学习
- `gamma`: 折扣因子（论文：0.99）
- `lr_rl`: Actor-Critic学习率（论文：1e-4）
- `lambda_rl`: RL损失权重（论文：0.1）

- `max_seq_len`: 150（↓计算量33%）
