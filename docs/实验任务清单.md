### 阶段3：基线模型对比实验 (4.4 + 4.5) ⏳

#### 任务3.1：实现基线模型
**状态**: ⏳ 待开始

需要实现以下5个基线模型：

1. **DKT** (Deep Knowledge Tracing)
   - 基于循环神经网络的经典知识追踪模型
   - 文件: `baselines/dkt.py`

2. **DKVMN** (Dynamic Key-Value Memory Network)
   - 基于记忆网络的知识追踪方法
   - 文件: `baselines/dkvmn.py`

3. **SAINT** (Separated Self-Attention)
   - 基于 Transformer 架构的序列建模方法
   - 文件: `baselines/saint.py`

4. **GKT** (Graph-based Knowledge Tracing)
   - 基于图神经网络的知识追踪模型
   - 文件: `baselines/gkt.py`

5. **DKTMR** (DKT with Multi-Relation)
   - 引入多关系知识点表征的改进模型
   - 文件: `baselines/dktmr.py`

#### 任务3.2：运行基线模型对比
**运行命令**:
```bash
python experiments/baseline_comparison.py --dataset assist09
python experiments/baseline_comparison.py --dataset junyi
python experiments/baseline_comparison.py --dataset ednet
```

**输出** (图4-1, 图4-2, 图4-3):
- 各模型在不同数据集上的 AUC 对比
- 各模型在不同数据集上的 ACC 对比
- 各模型在不同数据集上的 DOA 对比

### 阶段4：消融实验 (4.7) ⏳

#### 任务4.1：实现消融实验变体
**状态**: ⏳ 待开始

需要实现以下6个模型变体 (表4-3):

| 模型简称 | 说明 | 移除模块 |
|----------|------|----------|
| **KRD-KT** (完整) | 本文提出的完整模型 | 无 |
| **KRD-KT w/o 3WD** | 移除三支决策，使用标准GNN | 三支决策机制 |
| **KRD-KT w/o Multi-order** | 仅使用一阶邻居 | 多阶邻居分离 |
| **KRD-KT w/o Diff-Msg** | 所有邻居使用相同消息传递 | 差异化消息传递 |
| **KRD-KT w/o Decay** | 移除距离衰减权重 (ω(k)=1) | 距离衰减机制 |
| **KRD-KT w/o Neg-Supp** | 移除负域抑制 (γ_neg=0) | 负域抑制机制 |
| **KRD-KT-SL** | 移除强化学习，改为监督学习 | 强化学习框架 |

**实现文件**: `experiments/run_ablation.py`

**运行命令**:
```bash
python experiments/run_ablation.py --dataset assist09
python experiments/run_ablation.py --dataset junyi
python experiments/run_ablation.py --dataset ednet
```

**输出** (表4-3):
- 各变体模型的 AUC / ACC / DOA 对比表
