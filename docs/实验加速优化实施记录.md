### 1. AMP混合精度训练 ⭐⭐⭐⭐⭐

**收益**: 30-50%提速  
**实施状态**: ✅ 已完成

#### 修改内容

**文件**: `models/krd_kt.py`

1. **函数签名更新**:
```python
def train_krd_kt(..., use_amp=True, validate_every_n_epochs=1):
```

2. **初始化GradScaler**:
```python
# 初始化混合精度训练（AMP）- 提速30-50%
scaler = None
if use_amp and torch.cuda.is_available():
    scaler = torch.cuda.amp.GradScaler()
    print(f"✅ AMP混合精度训练已启用 (预期提速30-50%)")
```

3. **新增train_step_amp方法**:
```python
def train_step_amp(self, batch, concept_graph, scaler):
    """使用AMP混合精度的训练步骤（提速30-50%）"""
    with torch.cuda.amp.autocast():
        predictions, hidden_states = self.forward(batch, concept_graph)
        kt_loss, bce_loss, l2_reg = self.kt_loss_fn(...)
    
    self.kt_optimizer.zero_grad()
    scaler.scale(kt_loss).backward()
    
    if hasattr(self, 'grad_clip') and self.grad_clip is not None:
        scaler.unscale_(self.kt_optimizer)
        torch.nn.utils.clip_grad_norm_(self.parameters(), self.grad_clip)
    
    scaler.step(self.kt_optimizer)
    scaler.update()
```

4. **训练循环集成**:
```python
# Phase 1 和 Phase 2 训练循环
if scaler is not None:
    losses = model.train_step_amp(batch, concept_graph, scaler)
else:
    losses = model.train_step(batch, concept_graph)
```

#### 技术细节

- **FP16算力**: RTX 5070 Ti的FP16算力远超FP32
- **自动类型转换**: `torch.cuda.amp.autocast()`自动选择最优精度
- **梯度缩放**: 防止FP16下溢
- **梯度裁剪**: 在`scaler.step`之前`unscale_`
- **对结果影响**: 无，标准做法

## ⚠️ 注意事项

### 1. AMP混合精度

- ✅ 对大部分操作无影响
- ⚠️ 某些操作（如BatchNorm）会自动使用FP32
- ⚠️ 梯度裁剪需要在`scaler.step`之前`unscale_`
- ⚠️ PyTorch 2.7建议使用`torch.amp.GradScaler('cuda')`而非`torch.cuda.amp.GradScaler()`

### 2. 多进程加载

- ✅ 需要`if __name__ == '__main__':`保护
- ⚠️ Windows下worker数不要超过4
- ⚠️ 如果遇到问题，降回0

### 3. torch.compile

- ✅ 首个batch会慢（编译开销）
- ✅ 之后每个batch都更快
- ⚠️ 某些动态操作可能不支持
- ⚠️ 需要PyTorch ≥ 2.0

### 4. 验证频率

- ✅ 不影响训练过程
- ✅ Early stopping仍然有效
- ⚠️ 日志输出会减少
- ⚠️ 可以通过`validate_every_n_epochs`调整

### 5. 消融实验运行次数
