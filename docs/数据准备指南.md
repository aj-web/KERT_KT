## 🔧 数据处理流程

### 1. 数据下载
```bash
# ASSIST09 - 自动下载
cd data
python process_assist09.py

# Junyi - 已包含在项目中
# 数据位于 junyi/ 目录

# EdNet - 手动下载
# 按照 data/download_ednet_manual.md 说明
```

### 2. 数据预处理
每个处理脚本包含：
- ✅ 数据清洗（去除异常值）
- ✅ 时间过滤（保留合理时间范围）
- ✅ ID重编码（连续化）
- ✅ Q-matrix构建（题目-知识点关联）
- ✅ 概念图构建（知识点关系）
- ✅ 数据划分（train/val/test）

### 3. 数据格式
处理后的数据为pickle文件，包含：
```python
{
    'train': DataFrame,          # 训练集
    'val': DataFrame,            # 验证集
    'test': DataFrame,           # 测试集
    'n_students': int,           # 学生数
    'n_questions': int,          # 题目数
    'n_concepts': int,           # 知识点数
    'q_matrix': np.array,        # Q矩阵 [n_questions, n_concepts]
    'concept_graph': np.array    # 概念图 [n_concepts, n_concepts]
}
```

### 4. 数据加载
```python
import pickle

# 加载单个数据集
with open('data/assist09_processed.pkl', 'rb') as f:
    data = pickle.load(f)

# 或加载合并数据集
with open('data/processed_datasets.pkl', 'rb') as f:
    datasets = pickle.load(f)
    assist09_data = datasets['assist09']
    junyi_data = datasets['junyi']
```

## ⚠️ 常见问题

### Q1: ASSIST09下载失败？
**A**: 使用EduData库自动下载，如失败请手动下载：
- 链接: http://base.ustc.edu.cn/data/ASSISTment/
- 文件: 2009_skill_builder_data_corrected.zip

### Q2: Junyi处理很慢？
**A**: 原始数据2500万条，已实现采样（4%→100万）
- 修改采样率: `SAMPLE_RATE = 0.04` in `process_junyi.py`

### Q3: 概念图为什么稀疏？
**A**: 
- ASSIST09: 使用Q-matrix（共现）
- Junyi: 使用先修关系（有向图）
- 这是正常的，符合论文设定

### Q4: 如何验证数据正确性？
**A**: 
```bash
# 运行数据诊断
python experiments/inspect_pkl_data.py
```
